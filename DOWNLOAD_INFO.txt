================================================================================
TROUBLESHOOTING
================================================================================

Q: Port 3000 already in use?
A: npm run dev -- -p 3001

Q: Build fails with TypeScript errors?
A: rm -rf .next node_modules && npm install && npm run build

Q: Supabase connection error?
A: Verify .env file has correct URL & API key
   Check Supabase Dashboard > Project Status

Q: How do I add authentication?
A: Supabase Auth is optional. Edit lib/supabase.ts to add signUp/signIn.

Q: Can I use real HTML scraping?
A: Yes. Replace analyzeUrl() in lib/analyzer.ts with jsdom/cheerio.
